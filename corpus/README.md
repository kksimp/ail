# AIL corpus

Public, runnable AIL programs of 30 to 200 lines: text, data, files, concurrency, parsing, simulation and CLI tools.
Each `corpus/NAME/` holds `NAME.ail` (with `@test`s), `NAME.py` (a Python twin that prints the same output) and
`NAME.out` (the expected output, generated by the twin). The gate suite `corpus` builds every program, compares its
output with `NAME.out` and runs its tests. `python3 tools/check-corpus-py.py` checks the twins (`--write` regenerates the `.out`).

Rules for a program: deterministic (no clock, random numbers or network), files only under `fs.make_temp_dir`, no cwd dependence,
plain idiomatic AIL as the language card teaches it, and output that does not depend on map iteration order (sort keys).
