# Test fonts

`inconsolata-ascii.ttf` is Inconsolata (SIL Open Font License 1.1, see `OFL.txt`), instanced at regular width and weight and cut to U+0020-007E with `pyftsubset`. It is the real TrueType file the `std.app` `Font` tests send, so they need no network. Garlic and the hosts' own checks may reuse it.
