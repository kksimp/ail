# 1206. Three more certain fixes from the mistakes corpus: multiple assignment, module error names, `unwrap()` on a call

- **Status:** Accepted
- **Date:** 2026-11-26
- **Decided by:** AI (delegated, [ADR 0076](0076-delegated-decisions.md)); diagnostics and fixes only, no language change
- **Topic:** 22 — Tools
- **Spec rules:** `gram.foreign.1`, `err.use.1`, `expr.name.1`, fix.edit.2

## Context

135 of the 428 pairs in `tests/mistakes/` have no `.fixed` file. Most have no single correct rewrite
([the fix-rules note](../design/fix-rules.md) lists why: an arity error needs an argument the author must choose, a
missing std function has no substitute, a dropped task handle needs a decision about when to wait). Re-reading
the list after [ADR 1203](1203-certain-first-draft-fixes.md) found three groups where the rewrite is exact.

## Decision

- **`a, b = e1, e2`** (two names or field paths, one line, no comment) has the fix `assign through a temporary`
  (anchor `tuple_temp`, `compiler/fix/foreignfix.ail`). `a, b = b, a` is `t := a`, `a = b`, `b = t`. When `e1`
  makes no call it is `t := e2`, `a = e1`, `b = t`; otherwise each right side gets its own temporary, in order. Both
  right sides are read before either target changes, as the multiple assignment means. The temporary is `tmp_N`
  with `N` the line, and a name no line of the file contains as text, so two fixes of one file never declare the same
  name. [ADR 1202](1202-first-draft-foreign-habit-fixes.md) rejected this fix because it adds lines and invents a
  name; the name is now collision-proof and the audit names `a, b = b, a` as the commonest unfixed habit.
- **err.use.1 in `main` with a module's error type**: the signature fix `! E` was dropped whenever the error's name
  had a module part. It now writes the name as `error_written` does for err.type.3 and is offered only when the
  head of that name is a `use` alias of the file.
- **`x.unwrap()`, `x.expect(m)` and `x.unwrap_or(d)` where `x` is a call** (`f().unwrap()`, `parse(s).unwrap()`)
  take the existing `else` fix: `short_text` now reads a call with at most one short argument.

Left alone: `m.insert(k, v)` and `xs = append(xs, x)` (a rewrite is right only as a whole statement, which
the method-name diagnostic does not see); `sorted(desc: true)` (ties reverse); every group whose rewrite needs a
type, a default or a choice the program does not make.

## Options considered

- Reusing one name `tmp`: rejected, two swaps in one block would declare it twice.
- A certain `tmp` fix for a function-call right side in one temporary: rejected, it reverses the call order.
- Writing every module error as `E` bare: rejected, it names a type that is not in scope.

## Consequences

Untested at writing; the Mac job `fix-gaps/job.sh` runs the `mistakes`, `fix` and `golden` suites. The goldens of
`tests/golden/fix.tsv` for `go_multi_assign` change and are regenerated by the integrator.
