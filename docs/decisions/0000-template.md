# NNNN. Title in imperative form

- **Status:** Proposed | Accepted | Deferred | Superseded by [NNNN](NNNN-file.md) | Rejected
- **Date:** YYYY-MM-DD
- **Decided by:** designer name or role
- **Topic:** which of the design topics in [status.md](../status.md) this belongs to
- **Spec rules:** rule IDs this decision justifies, or "none yet"

## Context

The problem, the forces at play, and the constraints. Facts with sources where
they matter. Keep it short enough to read in one pass.

## Options considered

### Option A — name (chosen)
- **Pros:** …
- **Cons:** …

### Option B — name
- **Pros:** …
- **Cons:** …

## Decision

One or two sentences stating exactly what was decided.

## Rationale

Why this option beat the others in light of the project goals.

## Consequences

- What becomes easier.
- What becomes harder or is ruled out.
- Follow-up work or questions this creates.

## Rejected alternatives

For each option not chosen, one line on **why** it was rejected, so the debate
does not have to be repeated.
