# Standard modules: what the signatures do not say

> **Non-normative.** The module notes that `docs/quick-reference.md` keeps out of its page budget
> (ADR 0817). The [spec](spec/) is authoritative. Every signature is one command away: `ail card std.MODULE`
> lists a module's functions and `ail ask std WORDS` finds one by what it does. This table names each
> module and what is not in its signatures. Standard modules are in scope without `use`, except the
> parts that say `use std.NAME` (std.use.1, std.use.4).
