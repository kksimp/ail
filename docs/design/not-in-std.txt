# What `ail ask std WORDS` says when nothing in std matches (api.find.5).
# One line per topic: WORDS|WORDS -> ANSWER. A line answers when every word of one of its alternatives is in the query.
string builder|stringbuilder -> there is none and `+` does not join strings: push parts to a List[str], then parts.join("").
postgres|mysql -> no client for database servers in std. For an embedded SQL database use std.db (`db.open(path)?`, `d.exec(sql, params)?`, `d.query(sql, params)?`); for a server, write its protocol over std.net. To read a SQLite 3 file someone else wrote, use std.sqlite (`sqlite.open_file(path)?`, `d.scan(table)?`).
uuid|guid -> not in std. Build one from std.random bytes: random.int(0, 255) per byte, then bytes.hex().
websocket|websockets -> std.net.websocket: `use std.net.websocket`; `websocket.connect(url)?` (ws:// or wss://), `websocket.listen(addr)?` and `srv.accept()?`, `ws.send_text(s)?`, `ws.recv()?` (match m.kind), `ws.close(1000, "bye")`. Spec std.net.33.
http|https|request -> std.net: net.get(url), net.post(url, body, content_type), net.request(...). ail card std.net.
async|await|promise|future -> no async/await in AIL. Spawn tasks with `par`/`task` and wait on their handles: ail card tasks.
null|nil|undefined -> no null in AIL. Absence is T? and `none`: ail card absence.
exception|try catch|throw -> no exceptions. A function returns `T ! E`; handle it with `else` or `?`: ail card errors.
class|inheritance|interface -> use struct, enum, trait and impl: ail card traits.
lambda|closure -> `|x| expr` closures: ail card functions.
unwrap|expect -> there is no unwrap. Use `x else default`, `x else return`, or `x?`: ail card absence.
